# Product

## Register

product

## Users and purpose

DSH users queue nonurgent work from a conversation and inspect its progress in that same conversation. The management panel provides queue, usage statistics and settings.

## Design principles

- Follow the host application's existing visual language and theme tokens.
- Keep the composer and task status compact; reveal details on request.
- Make complete task content readable without entering edit mode.
- Preserve the existing Chinese and English interface support.
- Use semantic buttons, keyboard focus indicators and explicit expansion state.

## Boundaries

This is an embedded workflow tool. Avoid a separate visual identity or decorative controls that compete with the conversation.
